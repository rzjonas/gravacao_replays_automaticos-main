Guia Completo: Automação do InfinitePlay em um Novo PC

Este guia assume que você está em um sistema operacional baseado em Ubuntu/Debian.

Parte A: Pré-requisitos (Preparação do Ambiente)

Antes de configurar a automação, garanta que o projeto esteja funcional no novo computador.

    Copie os Arquivos do Projeto:

        Transfira toda a pasta do projeto (contendo infiniteplay_server.py, replay.py, etc.) para o novo computador. Um bom local seria, por exemplo, /home/seu_usuario/gravacao_replays_automaticos-main. Anote este caminho, pois você o usará várias vezes.

    Instale o Python e o Ambiente Virtual:
    Bash

sudo apt update
sudo apt install python3-venv

Crie e Ative o Ambiente Virtual:

    Navegue até a pasta do seu projeto:
    Bash

# Exemplo:
cd /home/seu_usuario/gravacao_replays_automaticos-main

Crie o ambiente virtual (a pasta .venv):
Bash

    python3 -m venv .venv

Instale as Dependências do Python:

    Ative o ambiente virtual:
    Bash

        source .venv/bin/activate

        Instale as bibliotecas necessárias (ex: mysql-connector-python, cloudinary). Se você tiver um arquivo requirements.txt, pode usar pip install -r requirements.txt.

        Após instalar, você pode desativar com o comando deactivate.

Parte B: Configuração da Automação

Agora, siga os passos para automatizar a execução.

Passo 1: Criar o Script "Porteiro" (start_if_in_window.sh)

Este script decide se o servidor principal deve ou não ser iniciado.

    Navegue até a pasta do seu projeto.

Crie o arquivo:
Bash

nano start_if_in_window.sh

Cole o conteúdo abaixo, lembrando de ajustar o caminho na penúltima linha para corresponder ao local do seu projeto no novo PC.
Bash

#!/bin/bash

DIA_SEMANA=$(date +%u)
HORA_ATUAL=$(date +%H%M)

HORA_INICIO=1850  # 18:50 
HORA_FIM=2230    # 22:30 

# Verifica se está entre Segunda (1) e Sexta (5) E dentro do horário 
if [ "$DIA_SEMANA" -ge 1 ] && [ "$DIA_SEMANA" -le 5 ] && \
   [ "$HORA_ATUAL" -ge "$HORA_INICIO" ] && [ "$HORA_ATUAL" -lt "$HORA_FIM" ];
then
  echo "Dentro do horário de operação. Iniciando o servidor..."
  # !!! ATENÇÃO: AJUSTE O CAMINHO ABAIXO !!!
  /home/seu_usuario/gravacao_replays_automaticos-main/.venv/bin/python infiniteplay_server.py [cite: 4]
else
  echo "Fora do horário de operação. O servidor não será iniciado."
  # Sai sem erro para o systemd não tentar reiniciar [cite: 5]
  exit 0
fi

Dê permissão de execução ao script:

Bash

    chmod +x start_if_in_window.sh

Passo 2: Criar o Serviço systemd (infiniteplay.service)

Este arquivo ensina o sistema operacional a gerenciar seu script como um serviço.

    Crie o arquivo de serviço:

Bash

sudo nano /etc/systemd/system/infiniteplay.service

Cole o conteúdo abaixo. É crucial que você altere o User, Group, WorkingDirectory e ExecStart para corresponder à sua configuração no novo PC.
Ini, TOML

    [Unit]
    Description=InfinitePlay Server for Automatic Recording and Replays [cite: 25]
    After=network.target [cite: 25]

    [Service]
    # !!! ATENÇÃO: AJUSTE O USUÁRIO E GRUPO ABAIXO !!!
    User=seu_usuario [cite: 27]
    Group=seu_usuario [cite: 27]
    # !!! ATENÇÃO: AJUSTE O CAMINHO DO DIRETÓRIO DE TRABALHO ABAIXO !!!
    WorkingDirectory=/home/seu_usuario/gravacao_replays_automaticos-main [cite: 28]
    # !!! ATENÇÃO: AJUSTE O CAMINHO PARA O SCRIPT "PORTEIRO" ABAIXO !!!
    ExecStart=/home/seu_usuario/gravacao_replays_automaticos-main/start_if_in_window.sh [cite: 8]

    Restart=on-failure [cite: 30]
    RestartSec=5s [cite: 25]

    [Install]
    WantedBy=multi-user.target [cite: 25]

    Salve e feche o editor (Ctrl + X, depois Y, e Enter).

Passo 3: Criar o Agendamento com cron

O 

cron será o responsável por ligar e desligar o serviço pontualmente nos dias de semana.

    Crie o arquivo de agendamento:

Bash

sudo nano /etc/cron.d/infiniteplay-schedule

Cole o conteúdo abaixo. Geralmente, este trecho não precisa de alterações.
Snippet de código

    # Inicia o serviço InfinitePlay às 18:50, de Segunda a Sexta [cite: 37]
    50 18 * * 1-5 root /usr/bin/systemctl start infiniteplay.service [cite: 37]

    # Para o serviço InfinitePlay às 22:30, de Segunda a Sexta [cite: 38]
    30 22 * * 1-5 root /usr/bin/systemctl stop infiniteplay.service [cite: 38]

Passo 4: Ativar e Iniciar o Serviço

Agora, vamos registrar e habilitar tudo no sistema.

    Recarregue o 

    systemd para que ele leia o novo arquivo de serviço que você criou:

Bash

sudo systemctl daemon-reload

Habilite o serviço para que ele seja iniciado automaticamente com o sistema (o script "porteiro" controlará se ele realmente deve rodar):

Bash

sudo systemctl enable infiniteplay.service

(Opcional) Você pode iniciar o serviço manualmente pela primeira vez para testar:
Bash

sudo systemctl start infiniteplay.service

(Opcional) E verificar seu status:
Bash

    sudo systemctl status infiniteplay.service

Seguindo este guia detalhado, você conseguirá replicar a automação em qualquer novo computador de forma consistente e segura.
